### How I work

- **Findings first.** Every analysis ends in a number someone can act on, with the caveats stated next to it.
- **Reproducible by default.** Pinned dependencies, runnable notebooks, reports in diffable formats.
- **Ship it.** Where it helps, the analysis becomes a tool, a dashboard or a live demo — not just a notebook.
